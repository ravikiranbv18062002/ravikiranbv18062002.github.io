DocuMind AI

Smart document copilot and retrieval assistant

A full-stack RAG chatbot for PDFs, built with FastAPI, React and PostgreSQL (pgvector) and tested on 50+ documents. It answers questions through semantic search, using Llama 3.1 8B on Groq for fast responses and Sentence Transformers for embeddings. Runs as three Docker Compose services (backend, frontend, database) on AWS EC2, with a smaller image from CPU-only inference.

Stock Assistant

RAG pipeline for stock research

Three independently deployable FastAPI services (ingestion, retrieval, chat) share one Postgres and pgvector database. A LangChain LCEL router decides whether a question needs price data from yfinance, news from NewsAPI, or both, then Groq writes a grounded answer. The chat service adds JWT login, saved per-conversation memory, and follow-up questions resolved by query condensing. Built for Docker Compose locally and AWS ECS/EKS in the cloud, with logging ready for CloudWatch.

  • LangChain LCEL
  • Microservices
  • JWT
  • pgvector
  • Groq
  • AWS ECS/EKS

TodoList

FastAPI-focused backend app

A full-stack to-do app with 12+ REST endpoints, cookie-based session login, and PBKDF2-SHA256 password hashing through Passlib. Per-user authorization keeps each person's tasks private across all CRUD operations. Structured logging covers requests, sign-ins and errors. Deployed with Docker on AWS EC2, using SQLite locally and PostgreSQL on the server through environment-driven config.
